## What it does

`main.ts` writes a single line of the worst possible advice an AI could give — concrete, followable, and immediately regrettable — to `/output/entry.txt`. The line is 114 characters, inside the competition's 1–140 character gate.

## Run

```sh
node main.ts
```

Requires Node 22 or later. No dependencies, no network access.
